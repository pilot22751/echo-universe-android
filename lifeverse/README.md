# VIDAVERSO — Simulador de vida (Android)
Este é um **jogo independente e original**, separado do ECHO UNIVERSE, armazenado em `lifeverse/` para evitar qualquer alteração nos arquivos do ECHO.

**Conteúdo:** 109 carreiras, 164 eventos narrativos com escolhas, 67 conquistas, mais de 15 países, edição de personagem, carreira, estudos, relacionamentos, patrimônio, negócios, política fictícia, realeza, crime fictício, aposentadoria, filhos, herança e vários finais. Sem anúncios, sem compras internas, sem conexão de internet.

## Compilar e baixar o APK
Abra `Actions → Compilar VIDAVERSO APK`. Depois de uma execução verde, baixe o artefato **VIDAVERSO-Android-APK** e extraia `app-debug.apk`.

O código-fonte em `source.tar.xz` é um projeto Gradle Android autônomo. `gradle -p lifeverse/build-src assembleDebug`.

**Atenção:** APK de testes. A assinatura debug não é estável para atualizações distribuídas. Faça backup JSON no jogo antes de reinstalar.

VIDAVERSO não é BitLife, não altera o aplicativo original e não distribui recursos premium protegidos de terceiros.
